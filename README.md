# kotlin-practices

Kotlin and Jetpack Compose practice projects.

## Practice_1: Mobility Lens

Single-screen Compose app covering the six dimensions that separate mobile
apps from stationary ones. Previous/Next navigation, input validation, and a
custom Material 3 theme.

Package: `io.github.aayushhks.mobilitylens`
minSdk 27, targetSdk 36, compileSdk 36

Report and screenshots: `Practice_1/report/`

Open `Practice_1` in Android Studio and run on an emulator.

## Practice_2: Focus Plan Builder

Single-screen Compose app that turns a study subject and available minutes
into a focused study plan with a duration category and a recommended break.
Derived button state, null-safe parsing, and state hoisting between
`FocusPlanRoute` and `FocusPlanScreen`.

Package: `io.github.aayushhks.focusplanbuilder`
minSdk 27, targetSdk 36, compileSdk 36

Details and screenshot: `Practice_2/README.md`

Open `Practice_2` in Android Studio and run on an emulator.
## Practice_3: Campus Event Explorer

Two screen Compose app for browsing campus events. Searchable `LazyColumn`
with stable keys, type-safe navigation that passes only the event ID, an
invalid ID fallback, and sharing through an implicit `ACTION_SEND` chooser.

Package: `io.github.aayushhks.campuseventexplorer`
minSdk 27, targetSdk 36, compileSdk 36

Details and screenshots: `Practice_3/README.md`

Open `Practice_3` in Android Studio and run on an emulator.
